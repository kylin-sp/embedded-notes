# 嵌入式学习笔记（问题 / 知识点 / 经验）

一个零依赖、单文件的嵌入式学习记录网页，数据保存在浏览器本地（localStorage）。既能记录遇到的问题，也能沉淀知识点和经验总结。

## 使用方法
1. 用浏览器（Chrome / Edge 等）直接打开 `index.html`，无需安装任何东西。
2. 点击右上角「＋ 新增记录」，选择类型（问题 / 知识点 / 经验总结）开始记录。
3. 支持全文搜索、按类型 / 状态筛选、星标收藏、多种排序。
4. 每条记录都可以随时「编辑」或「删除」；编辑时内容自动存草稿，误关不丢失。

## 功能
- 三种记录类型：问题（未解决 / 已解决）、知识点（学习中 / 已掌握）、经验总结（待实践 / 已验证），表单标签随类型联动
- 统计面板：总记录 / 问题 / 知识点 / 经验 / 已完成 / 掌握率，随增删改实时更新
- 搜索与筛选：标题 / 内容 / 标签 / 附件文件名全文搜索，按类型、6 种状态筛选，支持「星标优先」「未解决优先」排序
- 星标收藏：卡片与详情弹窗均可一键收藏，支持「只看星标」筛选
- 深色 / 浅色主题：一键切换并记住偏好（默认深色）
- 草稿自动保存：新增记录时输入实时保存，关闭 / 取消不丢失，重开自动恢复（草稿里的附件图片 / 文件也会一并恢复）
- 字数统计：编辑弹窗实时显示两个内容区域的字数
- Markdown 编辑与预览：编辑页签实时写，预览页签实时渲染
- 支持语法：标题、粗体 / 斜体 / 删除线、有序 / 无序列表、待办清单、表格、引用、代码块、行内代码、链接、图片、分隔线
- 快捷插入按钮：加粗、斜体、行内代码、代码块、H2 标题、列表、链接，选中文本后一键包裹，或直接插入
- 代码高亮：代码块支持 `c`、`cpp`、`python`、`shell`、`ini`、`asm`、`js`、`makefile` 等语言标签
- 代码复制：代码块右上角一键复制
- 语法速查：编辑区下方「Markdown 语法速查」折叠面板，随时查阅
- 快捷键：编辑弹窗内 `Ctrl+S` 直接保存
- 上传图片：编辑弹窗「添加图片」支持多选，自动压缩（最长边 1280px、质量 0.82，PNG 保留透明），可一键「插入」到问题 / 解决方案正文中显示
- 上传文件：编辑弹窗「添加文件」支持 PDF / 数据手册 / 代码文件等（单个 ≤ 3MB），详情页可直接点击下载
- 附件展示：卡片缩略图（最多 3 张图片 + 文件数量徽章）、详情页图片画廊、点击放大灯箱
- 导出 Markdown：按类型分组导出全部笔记（含星级标记、附件下载行），方便归档到本地文件
- 安全过滤：自动过滤 `javascript:` / `data:` 等危险链接，防脚本注入
- 备份与恢复：一键导出 JSON（附件以 base64 内嵌，随备份一起导出）；导入时可选「替换」或「合并」（按 ID 去重）
- GitHub 云同步：把笔记备份到自己的 GitHub 仓库，电脑和手机打开同一个网址即可互通；支持手动推送/拉取、「保存后自动同步」，同步时可选是否携带图片附件
- 示例数据：内置 5 条示例记录（问题 / 知识点 / 经验，含代码块、引用、表格、待办效果），可随意编辑或删除

## 数据说明
- 数据只保存在当前浏览器的 localStorage 中；换浏览器、换电脑或清理浏览器数据都会丢失。
- 附件（图片 / 文件）以 base64 内嵌存储，会明显占用 localStorage 空间（浏览器通常上限约 5MB）。若附件较多，建议及时导出 JSON 备份；当附件总占用超过约 3.5MB 时页面会弹窗提醒。
- 建议每次学习告一段落后点击「导出」保存 JSON 备份，之后可随时「导入」恢复。
- 需要跨设备同步时，点右上角「☁️ 云同步」：填仓库和 GitHub 令牌（建议创建 Fine-grained token 只授权本仓库 Contents 的 Read/Write），令牌仅保存在本浏览器。
- 如需彻底清空，使用页脚「清空全部数据」（有二次确认）。

## 自定义
- 记录类型与状态选项在 `index.html` 中的 `TYPES` 常量里修改。
- 分类列表在 `CATEGORIES` 常量里修改。
- 图片压缩参数（最长边 / 质量 / 单文件与总配额）在 `index.html` 附件区的 `ATT_LIMITS` 等常量里修改。
- 配色、圆角等样式在 `<style>` 顶部的 CSS 变量（`:root`）里调整。
- 代码高亮配色在 CSS 的 `pre code .tok-*` 系列规则里调整。
